\section{Execution Context \& Call Stack}
Bộ máy JavaScript (V8 Engine) xử lý mã nguồn qua hai pha: \term{Creation Phase} và \term{Execution Phase}.

\section{Scope, Closure \& Event Loop}
Khái niệm Phạm vi (Lexical Scope), Closure trong JavaScript và mô hình xử lý bất đồng bộ đơn luồng với \term{Event Loop}, \term{Microtask Queue} (Promises) vs \term{Macrotask Queue} (\codeinline{setTimeout}).
